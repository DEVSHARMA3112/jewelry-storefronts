# Jewelry Storefronts: Aurelle, Gemma & Grove, Lustre

One React app, three themed fine-jewelry storefronts built from a shared component library.

- **Live site:** <ADD YOUR VERCEL/NETLIFY URL>
- **Stack:** React 19, Vite, React Router 6, plain CSS with per-brand CSS variables (switched by `data-brand` from the route). No state library; cart uses React Context.

## Run it
```
npm install
npm run dev        # http://localhost:5173
npm run build      # production build to dist/
```
`npm run gen` regenerates the product JSON, placeholder artwork, sitemap and robots (it overwrites `public/images`, so skip it once you add real photos).

## Tech choices
- One `Landing`, `List` and `Detail` component for all brands; look comes from CSS variables, copy from `brands.js`.
- React 19 renders `<title>`, `<meta>`, canonical and JSON-LD inside components (no helmet library).
- Filters and sort are stored in URL query params. The slider and gallery use CSS scroll-snap.
- Every data view has skeleton, error with Retry, and empty states.
